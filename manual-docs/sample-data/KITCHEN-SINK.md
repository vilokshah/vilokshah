# Kitchen-sink sample document

Use **Appearance → Docs Stats → Create sample elements document** to publish a `manual_documentation` post that includes:

- Headings (H2 / H3)
- Paragraphs, links, bold/italic, inline code
- Ordered / unordered / nested lists
- Image + figure caption (theme SVG)
- Table
- Code block
- Callouts: `[md_info]`, `[md_tip]`, `[md_note]`, `[md_warning]`
- Tabs: `[md_tabs]` / `[md_tab title="…"]`
- Accordion: `[md_accordion]` / `[md_item title="…"]`
- Quote + separator

The sample is nested under your first configured version root when available (`content-elements-sample` slug).
